# dark-factory-sandbox

Throwaway target repository for the [Agent Sandbox Blueprints](https://github.com/5herlocked/agent-sandbox-blueprints)
Dark Factory demo. A labeled issue here becomes a reviewed PR written by an agent running in
a hardware-isolated sandbox. Nothing in this repo matters; it exists to be modified by a bot.

`app/index.js` exports a small calculator module. `npm test` runs `test/index.test.js`.
